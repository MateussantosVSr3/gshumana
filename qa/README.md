# Testing, Compliance & QA

Importe `features_azure.csv` e `test_cases_azure.csv` no Azure Boards; `features.md` e `test_cases.csv` são as versões detalhadas. Os testes cobrem caixa-preta, positivos e negativos, objetivo, preparo, entrada, passos e saída. Adicione o professor como Admin.

Depois, substitua os marcadores do relatório HTML por link/prints reais e gere o PDF com `generate-pdf.ps1`.
