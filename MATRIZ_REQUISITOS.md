# Matriz de requisitos do PDF

| Disciplina/requisito | Artefato | Estado |
|---|---|---|
| Ficha no início do README, ODS e impacto | `README.md` | Pronto |
| Registro de IA | `prompts.md` | Pronto |
| Pesquisa, pessoa real e fotos | `docs/pesquisa_de_campo.md` | Roteiro pronto; equipe deve coletar evidência real |
| SOA: domínio, banco, REST, Swagger, testes | `backend/` | Código pronto; executar com .NET 8 |
| C#: POO, DI, EF Core, LINQ, async | `backend/` | Código pronto; executar com .NET 8 |
| Cyber: PII, taint e Risco Cidadão | `cybersecurity/`, `entregas/` | Pronto; 4 testes aprovados, ZIP e dois prints gerados |
| ML: dados reais, modelo aceito, 10 combinações/3 hiperparâmetros, treino/teste | `ml/` | Notebook, relatório e automação prontos; executar em máquina com rede |
| Mobile: Expo, API/mock, banco e acessibilidade | `mobile/` | Código com SQLite pronto; instalar dependências e capturar prints |
| Linux: provisionamento, systemd, monitor, logs, falha | `infra/` | Scripts prontos; demonstrar em VM Ubuntu |
| IoT: ESP32 no Wokwi integrado | `iot/` | Circuito/código prontos; importar e publicar link |
| QA: Features, critérios e Test Cases | `qa/` | Conteúdo e PDF-base prontos; cadastrar no Azure e inserir prints |
| Vídeos e links externos | roteiros/READMEs | Dependem de contas e gravação da equipe |

“Pronto” significa artefato criado e validado no limite das ferramentas locais; não substitui a execução e as evidências exigidas no ambiente da disciplina.
