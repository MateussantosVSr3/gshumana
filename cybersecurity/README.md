# Cybersecurity — módulo PII e Taint Analysis

Execute `npm test`, `npm run audit` e abra `dashboard.html`. O módulo detecta CPF/e-mail/telefone/CEP, mascara PII, impede que entrada contaminada chegue ao log e calcula o indicador Risco Cidadão (0–100). Use apenas dados fictícios na demonstração.

## Evidências a capturar

1. terminal com quatro testes aprovados; 2. auditoria mostrando fluxo bloqueado e sanitizado; 3. painel em risco baixo e crítico; 4. vídeo curto explicando fonte, sanitizador, destino e fórmula. Compacte somente esta pasta para o ZIP.

O roteiro completo da demonstração está em [`ROTEIRO_VIDEO.md`](ROTEIRO_VIDEO.md).
